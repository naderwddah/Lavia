# لافيا — موقع صالون نسائي (الإصدار المحدّث)

موقع واجهة عربية RTL متجاوب مع الجوال والكمبيوتر، مبني باستخدام **HTML + CSS + JavaScript** دون أي مكتبات JavaScript أو خادم مطلوب لعرض الموقع.

## تشغيل سريع

- افتحي `Lavia-Standalone.html` مباشرة في المتصفح: نسخة واحدة مدمجة فيها ملفات CSS وJavaScript والصور، مناسبة للتجربة والعرض.
- أو افتحي `index.html` داخل مجلد المشروع الذي يحتوي بجانبه `styles.css` و`app.js` ومجلد `assets/`.
- لا تنقلي ملف `index.html` وحده بعيدًا عن بقية ملفات المصدر، وإلا فلن تظهر الصور والتنسيقات.

## الموجود في الموقع

- صور توضيحية مولّدة خصيصًا لهوية لافيا، محفوظة محليًا بصيغة WebP ومضغوطة لسرعة التحميل.
- ثمانية أقسام خدمات، تضم **120 خدمة** بحسب قائمة العميل، مع بحث عربي عن الخدمات وفتح وإغلاق الأقسام.
- أربع باقات مقترحة وثلاث أفكار عروض. المحتوى التسويقي مبدئي ويحتاج موافقة إدارة الصالون.
- اختيار الخدمات أو الباقات أو العروض يملأ نموذج طلب الموعد تلقائيًا.
- معاينة الطلب ونسخ تفاصيله؛ لا يوجد إرسال حجز فعلي أو تأكيد توافر أو دفع إلكتروني.
- حركات عند التمرير وتأثيرات صور وبطاقات، قائمة هاتف، شريط تقدم للتمرير، وزر حجز ثابت على الهاتف.
- دعم الحركة المخفّضة `prefers-reduced-motion` وإمكانية فتح القوائم بلوحة المفاتيح.

## قبل النشر

1. اعتمدي أسماء الباقات وتفاصيلها مع الصالون، وأضيفي الأسعار الحقيقية والعروض الفعلية وفترة صلاحية أي خصم. لا توجد أسعار أو خصومات مؤكدة في النسخة الحالية.
2. أضيفي معلومات التواصل الرسمية، موقع الفرع وساعات العمل بعد تأكيدها من العميل.
3. إذا أردتِ حجزًا فعليًا، اربطي نموذج الحجز بخادم أو واتساب رسمي بعد حصولك على رقم الصالون. النسخة الحالية تجهز نصًا للنسخ فقط.
4. الصور المستخدمة **تصورية مولّدة وليست صورًا حقيقية من الصالون**. استبدليها بصور حقيقية إذا طلب العميل ذلك.
5. راجعي وصف أي خدمة ومناسبتها مع إدارة الصالون قبل إطلاق الموقع للعميلات.

## التخصيص

- الألوان الأساسية في بداية `styles.css` داخل `:root`.
- كل الخدمات موجودة في `index.html` داخل `#services`؛ عند تعديلها سيقرأها `app.js` تلقائيًا لإظهارها في خيارات الحجز.
- أسماء الباقات في بطاقات `.bundle-card`، وأسماء العروض في `.offer-card`؛ قوائم الحجز تُنشأ تلقائيًا منهما.
- الصور في `assets/`: `hero.webp`, `nails.webp`, `facial.webp`, `bride.webp` ونظائرها المقتطعة `*-portrait.webp`.
- خطا الواجهة: El Messiri للعناوين وTajawal للنصوص عبر Google Fonts، مع خطوط بديلة في حالة عدم توفر الإنترنت.

**تقنية:** لا تُرسل بيانات الأسماء أو الهواتف إلى أي خادم من هذه النسخة. نص الطلب يتولد محليًا في المتصفح.
